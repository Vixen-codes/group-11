# GameFinder: COM1034 Group Design Exercise (Team 11)

A six-person University of Surrey team project (2025/26) to design a game-discovery application built on game metadata from the [RAWG API](https://rawg.io/apidocs).

## My role

Database engineering: SQL schema design, table relationships and relational modelling for the game, developer, platform and genre data.

## Repository contents

| Folder | Contents |
| --- | --- |
| `db/` | Database schema and related files |
| `docs/` | Sprint documents completed by the team |

## How we worked

- Sprint-based delivery with a shared documentation folder
- Feature branches, merge/pull requests and peer review
- 100+ commits across the team
