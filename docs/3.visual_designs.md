Home screen:
link

This mockup shows how the system will look once opened. The newly released section showcases the top recently released games so that the user can quickly see new games that they can play which they might have not seen or heard about before. The screen has a search bar in which the user can search for their desired game, the search bar also comes with a filter tab which allows the user to be more specific in their search to find games that are perfectly suited to their wants.
In the top right corner there is also a favourites icon which when pressed brings the user to a list of all their favourited games.


Game details screen:
link

This mockup shows how the program looks once a game has been selected. As seen below the picture of the game there is a play button which gives the user the option to watch a trailer of the game. On the right of the picture there is also all the details related to the game including a description, price, rating and all the additional DLC content that can be purchased alongside it.


Favourites screen:
link

This mockup displays the favourites screen which includes all the games which a user has added to favourites. These games can be selected to see all the details about the game and when more than one are selected the user can compare games side by side.

Filter screen:
link
This mockup shows the result of clicking the filter button, showing all the different ways in which a user can filter their search. The filter includes genre, release date, price and rating. This is essential for the user as it allows them to find games they will actually enjoy rather than just the latest releases/whats trending.
